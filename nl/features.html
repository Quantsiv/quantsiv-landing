04 Functies

Gebouwd voor het quantumtijdperk.

Ondersteuning voor veel talen

Herkent de meest gangbare cryptografische API's in Python, JavaScript, TypeScript, Java, Kotlin, Go, C, C++, C# en Swift, plus openssl-, ssh-keygen- en keytool-opdrachten in buildscripts.*

  • Python
  • JavaScript
  • TypeScript
  • Java
  • Kotlin
  • Go
  • C
  • C++
  • C#

Cryptografische inventaris (CBOM)

Maakt automatisch een standaard CycloneDX 1.6 CBOM van de cryptografie die in je repository's is gevonden, of importeert CBOM's van andere tools.

Risicobeoordeling

Rangschikt versleuteling naar hoe lang de gegevens geheim moeten blijven, en digitale handtekeningen naar hoe lang ze vertrouwd moeten blijven. De meest urgente punten komen eerst.

Controles bij elke build

Markeert automatisch, bij elke build, de kwetsbare cryptografie die een wijziging toevoegt. Brengt de controles naar pull requests voor vroege feedback.

Eenvoudige CI/CD-integratie

Werkt met GitHub Actions, GitLab, Jenkins en Azure DevOps. Scan op je eigen computer of in de pipeline die je al gebruikt.

  • GitHub Actions
  • GitLab
  • Jenkins
  • Azure DevOps

Sleutels, certificaten en TLS

Herkent de algoritmen en sleutelgroottes in sleutel- en certificaatbestanden, en peilt met één handshake de TLS-verbindingen van de servers die je opgeeft.

Infrastructuurconfiguratie

Vindt kwetsbare sleutel- en TLS-instellingen in Terraform-, Kubernetes- en CloudFormation-bestanden, en in configuratiebestanden van webservers, OpenSSL en OpenSSH in je repository.

Ondersteuning voor cryptowallets

Analyseert de code, niet de blockchain. Vindt secp256k1- en Ed25519-ondertekeningssleutels, Schnorr-handtekeningen en ECDH- en ECIES-sleuteluitwisseling in gangbare walletbibliotheken. Geeft migratieaanwijzingen tot de blockchain post-quantumhandtekeningen ondersteunt.

MCP-ondersteuning

Laat AI-codeassistenten via een alleen-lezen MCP-koppeling je cryptografieregels controleren terwijl ze code schrijven.

Suggesties voor de post-quantummigratie

Stelt de best passende standaard voor: ML-KEM, ML-DSA of SLH-DSA, of een hybride sleuteluitwisseling.

Offline scannen

Standaard draaien scans offline in je CI en blijft je broncode in je eigen omgeving. Resultaten bereiken Quantsiv alleen als je ze uploadt. Openbare repositories kunnen ook op de servers van Quantsiv worden gescand; private niet.

Analyse door een AI-agent

Een AI-agent analyseert elke bevinding in haar context en stelt een oplossing voor. Hij maakt verbinding met het model dat je kiest via zijn chat-completions-endpoint, bijvoorbeeld ChatGPT, Claude, DeepSeek of Grok, of een model dat je zelf host. Geen wijziging wordt gemerged zonder goedkeuring van de gebruiker.

*De dekking verschilt per taal. Patroonherkenning mist aanroepen via een alias of dynamische aanroepen, meegeleverde code en afhankelijkheden, en leest clouddiensten voor sleutelbeheer niet.
