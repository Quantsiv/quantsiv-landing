03 Come funziona

Come funziona Quantsiv

Quattro passi, dalla scansione del tuo codice a un registro standard (CBOM CycloneDX 1.6).

1. Individuare

Quantsiv cerca gli elementi crittografici nel tuo codice sorgente. Le scansioni vengono eseguite di default nella tua CI, così il codice resta nel tuo ambiente e Quantsiv riceve la CBOM e i dettagli dei rilevamenti soltanto se decidi di caricarli. Puoi anche far scansionare a Quantsiv un repository pubblico sui suoi server; i repository privati non vengono scansionati lì.

2. Analizzare

Ogni rilevamento viene confrontato con gli algoritmi vulnerabili ad attacchi quantistici e classificato in base al periodo di conservazione.

3. Classificare

Per ogni rilevamento, Quantsiv spiega il motivo della priorità assegnata e, quando l'utilizzo è sufficientemente chiaro, indica lo standard verso cui migrare.

4. Documentare

Quantsiv genera una CBOM in formato CycloneDX 1.6, un file SARIF compatibile con gli strumenti di analisi del codice e un report con i risultati ordinati per priorità. Inoltre gli agenti di IA possono utilizzare queste informazioni per suggerire alternative resistenti agli attacchi quantistici e aiutare a pianificare le modifiche. Quantsiv confronta i risultati di ogni build con l'ultima build del ramo principale, segnalando le regressioni.

* Risultati reali di Quantsiv da repo dimostrativa
