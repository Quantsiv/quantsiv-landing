04 Le funzionalità

Costruito per l'era quantistica.

Supporto per più linguaggi

Rileva le API crittografiche più comuni in Python, JavaScript, TypeScript, Java, Kotlin, Go, C, C++, C# e Swift, oltre ai comandi openssl, ssh-keygen e keytool presenti negli script di build.*

  • Python
  • JavaScript
  • TypeScript
  • Java
  • Kotlin
  • Go
  • C
  • C++
  • C#

Inventario dei componenti crittografici (CBOM)

Crea automaticamente una CBOM standard in formato CycloneDX 1.6 con gli elementi crittografici individuati nei repository o importa CBOM generate da altri strumenti.

Valutazione del rischio

Classifica la cifratura in base a quanto a lungo i dati devono restare segreti e le firme digitali in base a quanto a lungo devono essere considerate affidabili. I problemi più urgenti vengono messi in evidenza per primi.

Controlli a ogni build

Segnala automaticamente, a ogni build, gli elementi crittografici vulnerabili introdotti da una modifica. Integra i controlli nelle pull request per fornire un riscontro tempestivo.

Integrazione CI/CD semplice

Compatibile con GitHub Actions, GitLab, Jenkins e Azure DevOps. Esegui le scansioni sul tuo computer o all'interno della pipeline che già utilizzi.

  • GitHub Actions
  • GitLab
  • Jenkins
  • Azure DevOps

Chiavi, certificati e TLS

Riconosce gli algoritmi e la dimensione delle chiavi nei file di chiavi e certificati e sonda con un solo handshake le connessioni TLS dei server che indichi.

Configurazioni dell'infrastruttura

Individua le configurazioni vulnerabili relative a chiavi e TLS nei file Terraform, Kubernetes, CloudFormation e nei file di configurazione di web server, OpenSSL e OpenSSH presenti nel repository.

Supporto per portafogli crypto

Analizza il codice, non la blockchain. Individua chiavi di firma secp256k1 ed Ed25519, firme Schnorr e scambio di chiavi ECDH ed ECIES nelle librerie per wallet più comuni. Fornisce indicazioni per la migrazione fino a quando la blockchain non supporta firme post-quantum.

Supporto con MCPs

Tramite un connettore MCP in sola lettura, consente agli assistenti di IA di verificare le regole crittografiche mentre generano codice.

Suggerimenti per la migrazione post-quantum

Suggerisce lo standard più adatto: ML-KEM, ML-DSA o SLH-DSA o l'uso di uno scambio di chiavi ibrido.

Scansione offline

Per impostazione predefinita, le scansioni vengono eseguite offline nella tua CI e il codice sorgente rimane nel tuo ambiente. I risultati vengono inviati a Quantsiv soltanto se scegli di caricarli. Anche i repository pubblici possono essere scansionati sui server di Quantsiv; quelli privati no.

Analisi con agenti IA

Un agente IA analizza ogni rilevamento nel suo contesto e propone una correzione. Si collega al modello che scegli tramite il suo endpoint chat-completions, per esempio ChatGPT, Claude, DeepSeek o Grok, oppure uno ospitato da te. Nessuna modifica viene integrata senza l'approvazione dell'utente.

*Il livello di copertura varia in base al linguaggio. Il riconoscimento per pattern non rileva le chiamate con alias o dinamiche, il codice vendorizzato e le dipendenze, e non legge i servizi cloud di gestione delle chiavi.
