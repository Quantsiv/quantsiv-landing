How Quantsiv Works

Four steps, from scanning your code to a standard record (a CycloneDX 1.6 CBOM).

1. Discover

Quantsiv looks for cryptography in your source code. Scans run in your CI by default, so your code stays in your environment, and Quantsiv receives the CBOM and the finding details only if you choose to upload them. You can also have Quantsiv scan a public repository on its own servers; private repositories are not scanned there.

2. Analyze

Each finding is checked against quantum-vulnerable algorithms and ranked by its retention period.

3. Rank

For each finding, Quantsiv explains the priority and the standard to migrate to.

4. Document

Quantsiv generates a CycloneDX 1.6 CBOM, a SARIF file that works with code-analysis tools, and a report with the findings ranked by priority. An AI agent uses this information to suggest quantum-safe alternatives and help plan the changes. Quantsiv compares each build's results with the latest main-branch build, flagging regressions.
